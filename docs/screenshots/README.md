# UI screenshots

Demo data (`npm run dev --prefix ui`), 2× scale. Desktop 1280×900; phone 390×844. Shelf's populated states use sample data the script injects; the demo has no Libby shelf.

Regenerate: start the UI dev server, then `npm run screenshots` (`BROWSER_EXECUTABLE_PATH` or `BROWSER_CHANNEL` as for `npm run test:ui`). The script replaces this folder's PNGs; this file is kept.
